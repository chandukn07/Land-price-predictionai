## 📦 Installation

### Step 1: Navigate to Project

```bash
cd C:\Users\byath\OneDrive\Desktop\project
```

### Step 2: Install Frontend

```bash
npm install
```

**No configuration needed!** API URL auto-configured.

### Step 3: Install Backend

```bash
cd backend
pip install -r requirements.txt
```

**Packages installed:**
- Flask (Web framework)
- XGBoost, LightGBM (ML models)
- SHAP (Explainable AI)
- SQLAlchemy (Database)
- Pandas, NumPy (Data)

### Step 4: Done! ✅

**That's it!** Database auto-creates on first run.
